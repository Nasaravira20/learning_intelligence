# Evaluation review checklist

A person compares the evaluation with their own rating before this checklist changes a production decision.

- [ ] The question asks for the objective that was taught.
- [ ] Credit matches the portion of the objective the learner showed.
- [ ] A correct answer with weak reasoning was not marked mastered.
- [ ] Feedback names the missing part in original wording.
- [ ] Any misconception note is copied from the learner's own answer or reasoning.
- [ ] An uncertain result stayed in review.
- [ ] Mastery, when recorded, has observed evidence from the assessment.
